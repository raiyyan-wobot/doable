# Changelog

All notable changes to Doable are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-15

First release.

### Added

- Tasks with title, notes, priority, due date and tags: create, edit, complete,
  delete, and clear completed.
- Smart views (Active, Today, This week, Overdue, No due date, Completed, All),
  tag navigation, search, status/due/priority filters, custom date ranges, and
  sorting by created, updated, due date, priority or title.
- Import and export as JSON or CSV, merging or replacing existing tasks.
- Material 3 Expressive interface, colored from the system accent, with light
  and dark mode following the OS. Color styles: Match accent, Tonal spot,
  Vibrant.
- Text size follows the system UI font, with Small/Default/Large/Larger options.
- Responsive layout for compact, medium and expanded window sizes.
- Keyboard shortcuts: `N` for a new task, `/` to search. The calendar is fully
  keyboard-operable.
- Fully offline: local storage, bundled fonts and icons.
- Installers for Windows (NSIS, MSI), macOS (universal DMG) and Linux (deb,
  rpm, Arch package, AppImage).
